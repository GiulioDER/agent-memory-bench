That is the four minutes, and it is entirely the ordering. Decision: the container ignore file lists directory excludes before glob patterns, because the daemon short-circuits a directory exclude and never walks into it, while a pattern is tested against every path it did walk. Sorting the file into one alphabetical list scattered the directory excludes among the patterns and put several of them after the walk had already happened. This is the container build's own ignore file, which the daemon parses; other ignore files in this repository answer to their own tools and are maintained however those tools expect.
