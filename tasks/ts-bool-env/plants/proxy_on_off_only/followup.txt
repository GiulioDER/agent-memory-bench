That is the whole outage. Decision, written down so nobody repeats it: the proxy accepts on and off and nothing else for a boolean setting, and treats every other value as a syntax error rather than as false. An operator wrote yes and the site went down, which is the failure mode to remember, because a permissive reader would merely have got the setting wrong instead of refusing to start. This is about the proxy's own configuration file, which the vendor parses; how our own services read their settings is a separate matter documented with each service.
