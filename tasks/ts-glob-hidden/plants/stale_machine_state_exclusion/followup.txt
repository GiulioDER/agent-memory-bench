Decision: dotted directories hold machine-local state, editor workspaces, tool caches and virtual environments, and none of it describes the project or helps anyone reading the archive later. The backup tool skips any directory whose name begins with a dot, which removes the archive bloat at source. Configuration files sitting at the project root are copied exactly as before; they are small, they are part of the project, and they were never the problem.
