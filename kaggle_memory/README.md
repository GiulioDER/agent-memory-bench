# Memory discipline on Kaggle Benchmarks

The memory held fixed, the model varied: 24 scenarios, 216 items, two Kaggle tasks (`trust` and
`restraint`) whose average is the benchmark score. Design, predictions and exclusion rules are in
[preregistration 098](../preregistration/098-kaggle-memory-discipline.md), which freezes every file
below by hash.

| file | what it is |
|---|---|
| `scenarios.json` | the authored scenarios and the distractor pool |
| `items.py` | builds `items.json`; `validate` refuses any scenario the scorer could misattribute |
| `scoring.py` | the scorer, copied verbatim into both Kaggle task files |
| `tasks/*.py` | the Kaggle task files, generated by `scripts/build_kaggle_tasks.py` |
| `../scripts/analyze_kaggle_memory.py` | re-scores downloaded runs from the raw replies |

## Running it

Needs a Kaggle account with an API token in `~/.kaggle/kaggle.json` (create it on kaggle.com
under Settings, API). Then, one step at a time:

```bash
pip install kaggle kaggle-benchmarks
kaggle b init -y
kaggle b t models
kaggle b t push memory-discipline-trust -f kaggle_memory/tasks/memory_discipline_trust.py --wait
kaggle b t push memory-discipline-restraint -f kaggle_memory/tasks/memory_discipline_restraint.py --wait
kaggle b t run memory-discipline-trust -m <model> --wait
kaggle b t run memory-discipline-restraint -m <model> --wait
kaggle b t download memory-discipline-trust -o downloads
kaggle b t download memory-discipline-restraint -o downloads
python scripts/analyze_kaggle_memory.py downloads --out results/kaggle-memory-discipline-001
```

Grouping the two tasks into a benchmark is done on the Kaggle web UI; the CLI manages tasks only.

## Checks that need no Kaggle account

```bash
python -m kaggle_memory.items
python scripts/build_kaggle_tasks.py --check
python -m pytest tests/test_kaggle_memory_discipline.py -q
```
